# 내 계좌로 받는 투자 뉴스레터

PLUG로 보유 종목을 조회하고, Codex가 최신 뉴스·공시·재무제표를 조사해 **짧은 뉴스레터 + 상세 기업 분석**을 만듭니다. Gmail 플러그인으로 본인에게 보내고, Codex에서 매일 오전 8시에 반복합니다. 매매 주문 기능은 없습니다.

**[가상 뉴스레터 보기](https://youtube-jocoding.github.io/nhplug-investment-report/) · [상세 리포트 예시](https://youtube-jocoding.github.io/nhplug-investment-report/report.html) · [3분 촬영 순서](docs/FILMING.md)**

## 이 프롬프트를 Codex에 붙여 넣으세요

```text
https://github.com/youtube-jocoding/nhplug-investment-report 를 받아서 내 실제 계좌의 투자 뉴스레터를 만들어줘.

나는 개발자가 아니야. README.md, AGENTS.md, WORKFLOW.md를 읽고 설치부터 실행까지 직접 진행해줘. PLUG 앱키·앱시크릿은 채팅 대신 로컬 입력 화면에서 내가 넣도록 해줘. 이미 연결된 키가 있으면 재사용하고, 필요한 계좌와 시장만 선택하게 해줘. 우선 미국주식을 분석하되 실제 잔고가 없으면 조회 범위를 확인해줘.

내 보유 종목의 최신 공식 실적·재무제표·공시와 최근 7일 중요 뉴스를 실행 시점에 조사해줘. 매출, 이익, 현금흐름, 투자비, 현금·부채를 함께 읽고 보유 종목과 섹터의 성장 동력·위험·조건별 전망·다음 확인 지표를 설명해줘. 숫자의 단위·회계기간·발표일·원문 링크를 붙여줘. 확인하지 못한 사실은 미확인으로 남겨줘. 개인 성향이나 '내 기준'은 묻지 말고 매매 추천·목표주가·수익 보장 없이 근거 중심으로 분석해줘.

메일은 뉴스레터처럼 짧게: 핵심 진단 1줄, 종목별 1줄(최대 6종목), 주요 뉴스 2개, 다음 일정 1개. 전체 본문은 가급적 1,200자 안팎으로 만들고, 상세 재무표와 시나리오는 별도 HTML 리포트 첨부로 제공해줘. 모든 뉴스와 실적에는 원문 링크를 달아줘.

Gmail 플러그인을 확인하고 연결된 본인 계정으로 첫 리포트를 실제 발송해줘. 연결이 없으면 Gmail 연결 방법만 안내하고 SMTP 비밀번호나 별도 Google API 키는 요구하지 마. 발송 전 daily.py의 prepare/claim으로 중복을 막고, 성공 메시지 ID와 Gmail 검색으로 발송을 확인해줘.

이후 매일 오전 8시(Asia/Seoul)에 이 작업에서 Codex 예약 실행을 등록해줘. 매번 계좌를 새로 조회하고 자료를 재조사한 뒤 본인 Gmail로 보내야 해. 기존 예시의 날짜만 바꾸지 말고, 실패·불확실한 발송은 재전송하지 마. 중복 예약이 있으면 새로 만들지 말고 갱신해줘. 정기 실행에는 확정된 로컬 저장소의 절대 경로와 WORKFLOW.md 절차를 넣어줘. 컴퓨터·Codex 실행 조건과 첫 발송 결과, 다음 예약을 알려줘.
```

## 처음 한 번 필요한 것

- Codex 데스크톱 앱과 사용할 수 있는 Codex 이용량.
- 본인 PLUG 앱키·앱시크릿과 조회 가능한 계좌. 발급·지원 시장·이용 조건은 [PLUG 공식 안내](https://www.nhplug.com/intro)에서 확인합니다.
- Codex의 **Gmail 플러그인 설치 및 본인 계정 연결**. PLUG 키만으로 Gmail에 로그인할 수는 없습니다. 연결 후 별도 SMTP·Google·OpenAI API 키는 필요하지 않습니다.
- Python 3.10 이상, Node.js 22 LTS. Codex가 실행 환경을 확인하고 설치를 도와줍니다. 새 PC에는 키·계좌 선택·Gmail 연결을 다시 설정합니다.

일반 사용자는 위 프롬프트 이후 로컬 화면에 키를 넣고 계좌를 선택하면 됩니다. 매일 대신 매주를 원하면 마지막 문단의 시간을 “매주 월요일 오전 8시”로 바꾸세요.

## 리포트는 이렇게 만들어집니다

`PLUG 실제 잔고 → Codex 웹 조사 → 수치 검산 → 짧은 뉴스레터 + 상세 리포트 → Gmail 본인 발송`

| 메일에서 바로 읽는 내용 | 상세 리포트에서 읽는 내용 |
|---|---|
| 핵심 진단, 평가금액·미실현 손익 | 종목별 재무표, 기간·단위·전년 동기 비교 |
| 보유 종목별 핵심 한 줄 | 재무 해석과 기본·상방·하방 조건 |
| 중요한 뉴스 2개와 원문 | 섹터 전망, 다음 확인 지표, 공식 실적·공시 링크 |
| 다음 확인 일정 | 확인한 범위와 미확인 항목 |

실제 계좌는 공개 사이트에 올리지 않습니다. 메일 본문과 `report.html` 첨부로 다른 PC에서도 읽습니다. 로컬 화면의 “상세 리포트”와 공개 링크의 **가상 예시**는 서로 다른 자료입니다.

재무 수치는 코드가 검산하지만 뉴스·해석의 사실 여부를 자동 보증하지는 않습니다. 매 실행에서 Codex가 원문을 조사합니다. 잔고 새로고침 버튼은 기업 리서치를 자동 갱신하지 않습니다.

## 직접 실행할 때

macOS/Linux는 `./start`, Windows는 `start.cmd`를 실행하고 `http://127.0.0.1:8766`을 엽니다. 첫 실행에 라이브러리를 설치하고 화면을 빌드합니다. 다른 프로그램이 8766 포트를 쓰면 Codex에 알려주세요.

```bash
python3 scripts/bootstrap.py
.venv/bin/python server.py
# Windows: .venv\Scripts\python.exe server.py
```

분석·발송 단계는 [WORKFLOW.md](WORKFLOW.md)에 있습니다. 파이썬 코드 단독 실행은 웹 조사나 Gmail 전송을 수행하지 않습니다. **Codex와 Gmail 플러그인**이 이 단계를 실행합니다. 예약 시간은 작업 시작 시각으로, 조사·생성 후 메일이 도착합니다. 로컬 예약에는 컴퓨터와 Codex 실행, 네트워크·API·Gmail 인증이 필요하며 꺼진 PC에서의 정시 발송을 보장하지 않습니다.

## 데이터 범위와 보관

현재 어댑터는 선택한 한 계좌의 국내주식 또는 미국주식 잔고를 읽습니다. 다른 해외 시장·퇴직연금·부동산 등 전체 자산 통합은 지원하지 않습니다. 국내·미국 잔고의 현금을 합산하지 않아 중복 계산을 피합니다. 시장별 지원 항목은 공식 API 명세를 따릅니다.

키·정규화 잔고·발송 이력·실제 리포트는 Git에서 제외된 `private/`에 저장됩니다. macOS/Linux에서는 소유자 접근 권한을 설정하며 Windows는 해당 사용자 폴더의 접근 제어를 사용합니다. 계좌번호는 마스킹하며 키를 채팅·GitHub에 붙여 넣지 않습니다. Codex 분석 과정에는 정규화된 보유 정보가, Gmail 전송에는 리포트 내용이 사용됩니다.

예약 중단은 Codex의 해당 예약 작업을 일시 정지하거나 삭제하면 됩니다. 로컬 데이터 삭제는 서버를 종료한 뒤 `private/`를 삭제합니다. API 키 폐기는 PLUG 포털에서 처리합니다.
