# AI 뉴스 3분 삽입 촬영 순서

제공받은 심의안의 흐름(완성 리포트 → PLUG와 Codex 역할 → 보유 현황 → 예약 → 본인 이메일 수신 → 공식 안내)에 맞춘 제작용 예시입니다. 새 문구·화면·개인 리포트에 기존 심의가 자동 적용되는 것은 아닙니다. 원본 심의 문서와 실제 계좌 자료는 이 저장소에 올리지 않습니다.

| 시간 | 화면 / 동작 | 내레이션 예시 |
|---|---|---|
| 0:00–0:20 | Gmail에서 받은 짧은 뉴스레터 | “제 계좌에서 보유 종목을 읽고, 관련 뉴스와 기업 실적을 정리한 리포트를 제 이메일로 받아봤습니다.” |
| 0:20–0:45 | README 프롬프트를 Codex에 붙여 넣는 장면. 키 입력은 가림 | “PLUG API로 조회 가능한 계좌 정보를 읽고, Codex가 자료 조사와 리포트·메일 기능을 구성합니다. NH가 제공하는 완성형 리포트 서비스는 아닙니다.” |

| 2:30–3:00 | 저장소 프롬프트와 PLUG 공식 안내 | “아래 프롬프트를 넣고 본인의 PLUG 키와 Gmail을 연결해 활용할 수 있습니다. 개인 확인용이고 투자 판단을 대신하지 않습니다.” |

처음은 README 원샷 프롬프트. 설정 후 다시 촬영할 때는 아래처럼 기존 환경을 재사용합니다. 이미 보낸 날에는 같은 메일을 반복 발송하지 말고 수신된 메일과 실제 성공 기록을 보여줍니다.

```text
현재 저장소의 WORKFLOW.md대로 연결된 실제 계좌의 뉴스레터를 갱신해줘.
오늘 자료를 다시 조사하고, 핵심 한 줄·종목별 한 줄·뉴스 2개·다음 일정 1개로 짧게 정리해줘.
재무표와 조건별 전망은 상세 리포트에 넣어줘. 내 기준이나 매매 추천은 넣지 마.
이미 오늘 발송했다면 중복 발송하지 말고 기존 Gmail 결과를 보여줘.
```

촬영 체크:

- 시작/끝: “NH투자증권의 경제적 대가를 받고 제작되었음”. 상단: “NH투자증권 협찬광고”.
- 지속 안내: “개인 확인용 리포트이며 투자 판단을 대신하지 않음”. 공식 지원 기능·조건 확인, 특정 종목 추천·수익 보장 아님.
- 심의안의 원본 투자위험·수수료 고지와 심사필 문구는 원본 승인 범위·유효기간·지정 방식대로 영상 편집에 반영합니다. 웹 앱/개인 리포트의 인증처럼 사용하지 않습니다.
- 미래 수익률, 매수·매도 결론, ‘전문가가 보장’, ‘모든 PC에서 꺼져 있어도 발송’ 표현을 쓰지 않습니다.
- API 키·전체 계좌·Gmail의 다른 메일·수신 주소는 촬영에서 가립니다. 실제 개인 잔고 공개 범위는 촬영자가 선택합니다.
- 첫 수동 발송 결과와 향후 예약을 구분합니다. 실제 예약 실행 전에는 예약 이력이 성공한 것처럼 연출하지 않습니다.
