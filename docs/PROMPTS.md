```text
https://github.com/youtube-jocoding/nhplug-investment-report 를 받아서 내 실제 계좌의 투자 뉴스레터를 만들어줘.

나는 개발자가 아니야. README.md, AGENTS.md, WORKFLOW.md를 읽고 설치부터 실행까지 직접 진행해줘. PLUG 앱키·앱시크릿은 채팅 대신 로컬 입력 화면에서 내가 넣도록 해줘. 보안 저장소의 키를 재사용하고, 이 앱의 구버전 키 파일만 남아 있으면 실제 인증 후 한 번 암호화 이전해줘. 기존 계좌는 명확히 식별되는 경우 유지하고, .env나 환경변수 키는 사용하지 마. 키 발급 브랜드는 내가 직접 선택하게 하고 새 키 검증이 실패하면 기존 설정을 유지해줘. 필요한 계좌와 시장만 선택하게 해줘. 우선 미국주식을 분석하되 실제 잔고가 없으면 조회 범위를 확인해줘.

내 보유 종목의 최신 공식 실적·재무제표·공시와 최근 7일 중요 뉴스를 실행 시점에 조사해줘. 매출, 이익, 현금흐름, 투자비, 현금·부채를 함께 읽고 보유 종목과 섹터의 성장 동력·위험·조건별 전망·다음 확인 지표를 설명해줘. 숫자의 단위·회계기간·발표일·원문 링크를 붙여줘. 확인하지 못한 사실은 미확인으로 남겨줘. 개인 성향이나 '내 기준'은 묻지 말고 매매 추천·목표주가·수익 보장 없이 근거 중심으로 분석해줘.

메일은 뉴스레터처럼 짧게: 핵심 진단 1줄, 종목별 1줄(최대 6종목), 주요 뉴스 2개, 다음 일정 1개. 전체 본문은 가급적 1,200자 안팎으로 만들고, 상세 재무표와 시나리오는 별도 HTML 리포트 첨부로 제공해줘. 모든 뉴스와 실적에는 원문 링크를 달아줘.

Gmail 플러그인을 확인하고 연결된 본인 계정으로 첫 리포트를 실제 발송해줘. 연결이 없으면 Gmail 연결 방법만 안내하고 SMTP 비밀번호나 별도 Google API 키는 요구하지 마. 발송 전 daily.py의 prepare/claim으로 중복을 막고, 성공 메시지 ID로 sent를 기록한 뒤 Gmail에서 실제 본문·첨부를 대조해 verified로 확인해줘. 불명확한 응답은 uncertain으로 기록하고 재발송하지 마.

이후 매일 오전 8시(Asia/Seoul)에 이 작업에서 Codex 예약 실행을 등록해줘. 매번 계좌를 새로 조회하고 자료를 재조사한 뒤 본인 Gmail로 보내야 해. 기존 예시의 날짜만 바꾸지 말고, 실패·불확실한 발송은 재전송하지 마. 예약 이름과 이 저장소의 절대 경로가 같은 기존 예약이 있으면 새로 만들지 말고 갱신해줘. 정기 실행에는 확정된 로컬 저장소의 절대 경로와 WORKFLOW.md 절차를 넣어줘. 컴퓨터·Codex 실행 조건과 첫 발송 결과, 다음 예약을 알려줘.
```
